# Bazzite 遊戲入門 

## 常見思維的轉變

在 Linux 上運行遊戲是一個相當新興的範疇。透過各式各樣的開源工具，絕大部分的 Windows 遊戲大致上都能於 Linux 上運行。若你在 Linux 上運行遊戲，在某些情況下你能得到更好的遊戲體驗，如更少的顯示延遲、更平穩的幀率、更少的內存佔用等。

### Steam 遊戲

在大部分情況下，由於其包含內建的 [Proton 轉譯層](/General/terms/#bazzite_1)， Steam 都是在 Bazzite 上運行電腦游戲的推薦辦法。 雖然在某些情況下，在 Linux 上運行遊戲的體驗略顯粗糙，但絕大部分單機遊戲都能透過 Proton 轉譯層完美運行。

可惜，有的 DRM 、反作弊系統及遊戲公司極力阻撓在 Linux 上運行牠們的軟件，這是無解的。對於這種情況，若你仍想遊玩這些遊戲，那目前可見的唯一解決辦法是進入 Windows 和／或 設置 Windows／Bazzite 雙啟動。

### 非 Steam 遊戲

<small>_至此，我們已將可觀測宇宙中的所有內容（由 Steam 遊戲……至非 Steam 遊戲）納入 Bazzite 指南 。世界的真理，我已解明！_</small>

Bazzite 還包括 Lutris （一個管理和使用Proton／WINE的介面／前端）以供運行非 Steam 的 Windows 遊戲及軟件。此外，你亦可從 Bazaar 應用商店中安裝介面更加簡潔的 [**Faugus Launcher**](https://flathub.org/zh-Hant/apps/io.github.Faugus.faugus-launcher) 。此外，Bazzite亦建議使用 [**Heroic Games Launcher**](https://flathub.org/zh-Hant/apps/com.heroicgameslauncher.hgl) 管理及運行從 Epic Games 啟動器、GOG和Amazon 遊戲啟動器中購買的遊戲。

除透過雲端遊戲串流客戶端（大部分遊戲需 Game Pass Ultimate 方能從雲端串流），如 [**Greenlight**](https://github.com/unknownskl/greenlight) 外，絕大部分從 Microsoft Store 購買和安裝的遊戲無法在 Linux 上運行。此外，有一些 Game Pass 遊戲亦可透過 [Battle.net](https://us.support.blizzard.com/en/help/article/000367382) 於 Lutris 上運行。

主機模擬器如 [**Retrodeck**](https://flathub.org/en/apps/net.retrodeck.retrodeck) 和 [**Emudeck**](https://www.emudeck.com/) 大多都能從 Bazaar 應用商店或於 Bazzite Portal 上安裝。
